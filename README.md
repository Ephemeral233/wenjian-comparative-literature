# 文间 中英文学文化对读

公开网站：https://ephemeral233.github.io/wenjian-comparative-literature/

面向大学生的比较阅读教学原型，属于教育文化方向。当前包含三个主题单元、六部作品、九道有解析的练习，以及开放比较任务。

## 已实现

- 按思乡、自然、时间筛选；按作者、作品和主题搜索。
- 中英原文节选并排阅读，手机窄屏上下排列；支持大字模式。
- 文本细读、文化语境、比较练习三个阅读页签，可用方向键切换。
- 单元练习即时反馈，保留修改选项再试的机会。
- 本机已读进度和札记保存，Markdown 下载包含未保存的当前文字。
- 六个原文来源入口，以及版本、解释范围和译读归属说明。

网站无需账号，没有分析追踪代码或后台接口。札记只存于当前浏览器，不会跨设备自动同步。浏览器无法保存时会提示失败；清理数据前应下载札记。

## 内容范围

1. 李白《静夜思》与 Robert Burns 的 My Heart’s in the Highlands。
2. 柳宗元《江雪》与 William Wordsworth 的 I Wandered Lonely as a Cloud。
3. 晏殊《浣溪沙·一曲新词酒一杯》与 William Shakespeare 的 Sonnet 18。

英国文学范围包括苏格兰作家。这里只做主题并置，不据此主张直接影响关系；比较提示属于项目编写的讨论示例。经典原文采用短节选，不转载现代译本。来源链接、版本提示见网页与 content.js。

## 开发和发布

这是不需要构建步骤的静态网站。用任意静态 HTTP 服务预览本目录，修改后推送 main，GitHub Pages 从仓库根目录发布。

- index.html：页面结构。
- style.css：视觉样式及手机适配。
- content.js：作品信息、来源、提示和练习。
- app.js：筛选、阅读、反馈及本机保存。

代码采用 MIT 许可。原创导读与练习允许教学使用和改编，请保留项目与原文出处。原作节选和所链接版本的权利归属另见来源。

本仓库是研究原型，不包含申请人的身份资料、申报申请书或学习者数据。后续扩展单元与学习效果验证仍属于计划，未以虚构访谈或统计结果作背书。
